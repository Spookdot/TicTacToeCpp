# Tic Tac Toe CPP

This is an attempt to implement Tic Tac Toe with raylib-cpp in C++ obeying C++23 standards. For this I've used CPM and clang-tidy to attempt to get optimal readable and error-free code in effort to learn how to apply these tools and principals to all my code.
